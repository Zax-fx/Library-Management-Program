# Library Management System (Version 2)

An object-oriented Library Management System built in Python.

## Overview

This project simulates a simple library where administrators can manage books and members can borrow and return books. All data is stored using JSON files, allowing information to persist between program runs.

## Features

- Admin authentication
- Member authentication
- Add books
- Remove books
- Borrow books
- Return books
- Transaction history
- Persistent data storage using JSON
- Object-Oriented Programming (OOP)

## Technologies Used

- Python
- Object-Oriented Programming
- JSON
